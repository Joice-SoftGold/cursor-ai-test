STEP 2: Deploy to Your Azure Ubuntu Server
------------------------------------------

Quick Commands:
  
  1. Fix SSH key permissions:
     chmod 400 ~/path/to/your-key.pem

  2. Connect to server:
     ssh -i ~/path/to/your-key.pem azureuser@YOUR_SERVER_IP

  3. Install Nginx (on server):
     sudo apt update && sudo apt install nginx -y

  4. Configure firewall (on server):
     sudo ufw allow 80/tcp && sudo ufw enable
     
     Also open port 80 in Azure Portal:
     VM → Networking → Add inbound rule → Port 80

  5. Setup directory (on server):
     sudo mkdir -p /var/www/documind
     sudo chown -R $USER:$USER /var/www/documind

  6. Configure Nginx (on server):
     sudo nano /etc/nginx/sites-available/documind
     [Copy config from DEPLOY_GUIDE.md]
     sudo ln -s /etc/nginx/sites-available/documind /etc/nginx/sites-enabled/
     sudo systemctl reload nginx

  7. Upload files (from your machine):
     ./upload.sh
     OR
     scp -i ~/key.pem *.html azureuser@IP:/tmp/
     Then: sudo mv /tmp/*.html /var/www/documind/

  8. Visit: http://YOUR_SERVER_IP
